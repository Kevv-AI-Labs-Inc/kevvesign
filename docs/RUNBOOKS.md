# Signing operations

Current production procedures are in [SIGNING_OPERATIONS.md](SIGNING_OPERATIONS.md) and [DEPLOYMENT.md](DEPLOYMENT.md). Documenso is the sole editor, signing and finalization engine; the bridge owns identity mapping and durable business synchronization.

The former SQL Ledger, native session, Azure finalizer and legal-hold procedures are preserved in [the historical runbook](archive/native-platform-2026-09-12/RUNBOOKS.md). They describe the removed implementation and must not be used as assertions about the current platform.
